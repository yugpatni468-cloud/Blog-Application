# Blog Application

A responsive frontend blog application built using HTML, CSS, and JavaScript.

## Features

- User Registration
- User Login
- Logout
- Login Protection
- Create Blog
- Dynamic Blog Dashboard
- Delete Blog
- Dynamic Home Page
- Responsive Design
- Local Storage

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## Pages

- Home
- Login
- Register
- Dashboard
- Create Blog

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Open `index.html` using Live Server.
4. Register a new account.
5. Login and start creating blogs.
